Appendix A · Glossary

按首次出现顺序排列

每个词条给出英文术语、中文解释，以及它首次出现的章节锚点——点右侧链接可以直接跳到该概念被讲清楚的地方。全书共 54 条。

本表按术语在书中出现的先后排列，而不是按字母顺序——因为这些概念是层层搭建起来的，顺着读一遍，本身就是一次全书复习。

  • natural frequencies自然频率
    用「1000 人里有几人」而非百分比来表述概率的格式。分母不再隐形，贝叶斯推断被消化进叙述结构。全书方法论支柱。　→ 0.1
  • base rate neglect基础率忽视
    只盯着证据的强度（检测多准），忽略了事件本身的稀有程度（病多罕见）。　→ 0.1
  • conjunction fallacy合取谬误
    认为「A 且 B」比「A」更可能。子集不可能大于母集，错误来自用「像不像」代替「有多可能」。　→ 0.1
  • representativeness heuristic代表性启发式
    被问概率时，大脑悄悄换成「相似度」来回答。合取谬误与随机性错觉的共同源头。　→ 0.1
  • frequentist频率派
    把概率理解为「长期重复中出现的比例」。要求事件可重复，靠数据检验。　→ 1.1
  • Bayesian贝叶斯派 / 信念派
    把概率理解为「对某命题的相信程度」，可随证据更新。适用于一次性、不可重复的事件。　→ 1.1
  • law of large numbers大数定律
    重复次数越多，比例越接近真实概率。注意它保证的是比例收敛，不保证次数差缩小。　→ 1.1
  • calibration校准
    检验概率预报的方法：把所有说过「70%」的场合攒成一类，看其中真正发生的是否约七成。　→ 1.1
  • conditional probability条件概率
    P(A|B)：把不满足 B 的样本划掉之后，A 所占的比例。本质是「换了个分母」。　→ 1.2
  • independence独立性
    知道一个事件发生了，对另一个的概率毫无影响。只有独立时才可以把概率相乘。　→ 1.2
  • confusion of the inverse逆条件混淆
    把 P(A|B) 当成 P(B|A)。医学里表现为基础率忽视，法庭上表现为检察官谬误。　→ 1.2
  • expected value期望值
    把每种结果乘以出现频率再相加；等价于「玩很多次，平均每次的收支」。　→ 1.3
  • variance方差
    结果围绕平均值散开的程度。期望值相同的两个赌局，方差可以天差地别。　→ 1.3
  • absorbing state吸收态
    一旦进入就再也出不来的状态（破产）。它让「重复很多次」的前提失效，期望值随之失去意义。　→ 1.3
  • likelihood ratio似然比
    LR = P(证据|假设真) ÷ P(证据|假设假)。一条证据的力度表；LR=1 表示毫无信息量。　→ 2.2
  • odds赔率
    把「20% 概率」说成「1 比 4」。赔率形式下贝叶斯更新退化为乘法。　→ 2.2
  • prior / posterior先验 / 后验
    看证据之前 / 之后的信念。上一轮的后验就是下一轮的先验。　→ 2.2
  • prosecutor's fallacy检察官谬误
    把 P(证据|无辜) 当成 P(无辜|证据)。法庭版的逆条件混淆。　→ 2.3
  • defence attorney's fallacy辩护律师谬误
    反向的错误：假装本案只有这一份证据，因此每个随机匹配者嫌疑均等。　→ 2.3
  • database search effect数据库搜索效应
    搜索的池子越大，一次「命中」携带的信息量越小。同一份证据证明力可差几千倍。　→ 2.3
  • Cromwell's rule克伦威尔规则
    除非逻辑上不可能，否则永不给某命题 0 或 1 的概率——否则任何证据都再也推不动它。　→ 2.4
  • unfalsifiability不可证伪性
    一个能预测任何观测结果的理论，对任何证据的似然比都是 1，因此永远学不到东西。　→ 2.4
  • cognitive dissonance认知失调
    信念与证据冲突时的心理张力。有时不靠修改信念化解，而靠修改对证据的解释。　→ 2.4
  • Monty Hall problem蒙提霍尔问题
    三门游戏。主持人知情时换门胜率 2/3；主持人随机开门时两者各 50%。　→ 3.1
  • birthday problem生日悖论
    23 人房间里存在同生日的概率过半。因为该数的是配对数 n(n−1)/2，不是人数。　→ 3.2
  • birthday bound生日界
    撞车所需次数约为可能性总数的平方根。160 位哈希的碰撞强度只有 2^80。　→ 3.2
  • collision碰撞
    两个不同输入产生相同哈希值。密码学中生日界直接决定其难度。　→ 3.2
  • Simpson's paradox辛普森悖论
    每个分组里成立的关系，合并之后可以完全反过来。合并均值是按人数加权的。　→ 3.3
  • confounder混杂因素
    同时影响「原因」与「结果」的第三个变量。它发生在原因之前，必须分组控制。　→ 3.3
  • collider对撞因子
    被两个变量共同影响的结果变量。控制它反而会凭空制造出相关性。　→ 3.3
  • sample space样本空间
    一个随机情境下所有等可能结果的集合。条件概率就是在样本空间上筛格子。　→ 3.4
  • two children problem两个孩子问题
    「有两个孩子，其中一个是女孩，两个都是女孩的概率？」答案取决于这条信息是怎么产生的。　→ 3.4
  • gambler's fallacy赌徒谬误
    以为独立事件会「补偿」前面的偏差。大数定律靠分母稀释，不靠纠偏。　→ 4.1
  • hot-hand fallacy热手谬误
    以为连号意味着「势头」。与赌徒谬误方向相反，病根相同：认定连号需要解释。　→ 4.1
  • law of small numbers小数定律
    错误地期待小样本呈现出与大样本相同的规律性。　→ 4.1
  • regression to the mean回归均值
    按极端表现挑出的样本，下一次会向平均值靠拢。不是力量，是「挑选」的算术后果。　→ 4.2
  • control group对照组
    同样极端但不接受干预的一组。回归均值会同时作用于两组，因而在组间比较中被抵消。　→ 4.2
  • Poisson distribution泊松分布
    随机撒点时每个格子里点数的分布。它预测大量空格与少量扎堆同时存在。　→ 4.3
  • clustering illusion聚类错觉
    把随机分布必然产生的扎堆误读为有原因的聚集。　→ 4.3
  • Texas sharpshooter fallacy德州神枪手谬误
    先在数据里找到异常，再围绕它划定范围提出假设，然后用同一批数据「验证」。　→ 4.3
  • survivorship bias幸存者偏差
    只能观察到「活下来的样本」，而筛选标准恰与研究问题相关，导致系统性误判。　→ 4.4
  • selection effect选择效应
    样本进入数据集的机制本身携带信息。幸存者偏差是它最常见的一种。　→ 4.4
  • St. Petersburg paradox圣彼得堡悖论
    期望值无穷大的赌局，人们却只愿出十几元。期望效用的起点。　→ 5.1
  • expected utility期望效用
    用效用（而非金额）的期望来做决策。财富的边际效用递减。　→ 5.1
  • certainty equivalent确定性等价
    让你与某个赌局无差别的那笔确定的钱。它可以为负而期望值为正。　→ 5.1
  • Kelly criterion凯利公式
    最大化长期增长率的下注比例 f* = (p(b+1)−1)/b；赢亏对等时即 p−q。　→ 5.2
  • median vs mean中位数与均值
    右偏分布下两者可以天差地别。均值属于集合，中位数属于个人。　→ 5.2
  • fat tails肥尾
    极端事件的概率远高于正态分布的预测。中心极限定理的前提被破坏时出现。　→ 5.3
  • black swan黑天鹅
    认知之外、冲击极大、事后被编出「本该预见」解释的罕见事件。　→ 5.3
  • extreme value theory极值理论
    专门估计分布尾部的方法，不依赖于「见过多少次极端事件」。　→ 5.3
  • ergodicity遍历性
    「很多人各做一次」的平均是否等于「一个人做很多次」的结果。期望值算的永远是前者。　→ 5.4
  • ensemble average集合平均
    一群人各做一次的平均结果。期望值就是它。　→ 5.4
  • time average时间平均
    一个人重复做很多次后的结果。你实际经历的是这个。　→ 5.4
  • precautionary principle预防原则
    面对不可逆、系统性、无法试错的风险时，直接消除风险而非计算概率。　→ 5.4
