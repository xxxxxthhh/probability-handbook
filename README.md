# 概率直觉手册 · Probability Intuition Handbook

面向普通读者的双语交互式 HTML 电子书。手册系列「通识线」第一本。
核心卖点：每章一个可交互实验，读者亲手拖动参数，看直觉在自己眼前被数学纠正。

**状态：全书已完成。** 20 章正文（含导读）+ 2 附录 + 目录页，20 个交互实验，共 23 个页面。
直接用浏览器打开 `index.html` 即可阅读，无需任何构建步骤或本地服务器。

```

├── firstaid.html         # 附录 B 直觉急救卡（37 张，可打印）
├── chapters/             # 20 章正文，命名为 part-章-slug

```

## 交互实验

原生 JavaScript，无框架、无追踪、不写入任何浏览器存储（刷新即重置）。
每个实验配 2–3 个预设按钮；**默认参数下的结论一律写在正文里**，因此禁用
JavaScript 或阅读打印版时，全书论证不缺任何一环。

模拟类实验（抛硬币、蒙提霍尔、凯利路径等）默认用固定随机种子渲染，以保证
正文与打印版里引用的数字就是读者看到的数字；「再跑一轮」按钮才换种子。

## 打印 / 导出 PDF

任意页面直接浏览器打印即可：强制浅色、隐藏切换按钮与滑块、展开全部 quiz 答案、
交互组件降级为默认参数的静态说明（每个实验通过 `data-print-note` 携带自己的快照文字）。
`firstaid.html` 专门按单页速查表优化。
