全书每一个谬误压缩成三行：它叫什么 → 症状长什么样 → 一句话解药。右下角的链接回到讲透它的那一章。

打印说明：这一页是按打印优化的——直接用浏览器打印（Ctrl/Cmd + P）即可得到一份强制浅色、卡片不跨页断开的速查表。建议贴在你需要做判断的地方：会议室、交易屏旁边、或者写周报的桌角。

基础率忽视
base rate neglect
症状：听到「这个检测 99% 准确」，就觉得阳性等于确诊。
解药：先问「1000 个人里，本来有几个？」——罕见的东西，误报的绝对人数能轻松压过真阳性。
→ 2.1 医疗检测悖论
合取谬误
conjunction fallacy
症状：细节越多的故事听起来越可信：「他是程序员，而且爱爬山」比「他是程序员」更像真的。
解药：每加一个「而且」，概率只会变小，不会变大。子集装不下母集。
→ 0 导读
估测语言歧义
words of estimative probability
症状：「应该没问题」「很有可能」——说的人和听的人心里的数字差着两三倍。
解药：把词翻译成数字：「十次里有几次？」或者「赔率多少你才觉得公平？」
→ 1.1 概率是什么
把收敛当成纠偏
law-of-large-numbers misread
症状：以为「抛得越多越平均」意味着偏差会被补回来。
解药：比例收敛靠分母稀释，不靠补偿——次数差其实还会越拉越大（约按 √n 增长）。
→ 1.1 概率是什么
逆条件混淆
confusion of the inverse
症状：听到「得流感的人 80% 会发烧」，就以为「我发烧了有 80% 是流感」。
解药：问自己：分母换了没有？「发烧的人」和「流感的人」是两群人，两个方向没有理由相等。
→ 1.2 条件概率与独立性
乱相乘
false independence
症状：把两个概率相乘算「都发生」的概率，却没检查它们独立不独立。
解药：按下计算器前先问：这两件事有没有可能被同一个原因同时推动？同一家庭/地点/设备中一条就别乘。
→ 1.2 条件概率与独立性
只看期望值
expected-value tunnel vision
症状：算出期望值为正就下重注，不问最坏结果扛不扛得住。
解药：三连问：期望值多少？方差多大？最坏结果我扛不扛得住？第三问往往是决定性的。
→ 1.3 期望值
返奖率当中奖率
payback vs hit rate
症状：「返奖率 50%，买两注该中一注」——把总额比例当成了中奖频率。
解药：返奖率决定发回多少钱，奖级结构决定发给谁。两者毫不相干。
→ 1.3 期望值
同源证据重复计数
double-counting evidence
症状：好几条线索都指向同一个结论，于是信心爆棚——却没发现它们来自同一个源头。
解药：问：如果第一条已经知道了，第二条还能新增多少信息？一屋子人同意，可能只因为都读了同一篇报道。
→ 2.2 贝叶斯更新
把「没找到」当「不存在」
absence-of-evidence overreach
症状：搜过了没发现，就当作已经排除。
解药：按你找得有多认真打个折：漏检率 50% 的搜索只把概率砍一半，永远不该归零。
→ 2.2 贝叶斯更新
无信息量的「证据」
likelihood ratio ≈ 1
症状：一句听起来很准的话让你改变了判断，可它对谁都成立。
解药：问：如果结论是反的，我还会看到这条吗？答「大概也会」就扔掉。
→ 2.2 贝叶斯更新
检察官谬误
prosecutor's fallacy
症状：「这么巧的事，随机发生的概率只有百万分之一，所以他一定有罪。」
解药：那个数字回答的是「无辜的话会不会这么巧」。要定罪得问反方向，而这需要另一个基础率。
→ 2.3 检察官谬误
忘了问池子多大
database search effect
症状：在庞大数据库里搜出一个匹配者，就当成铁证。
解药：先算：池子里预计有几个无辜者也会匹配？500 万人 × 百万分之一 = 5 个。命中只是线索，不是结论。
→ 2.3 检察官谬误
先验封闭
prior closure
症状：「这事绝无可能」「我绝对不会错」——于是再多证据也推不动分毫。
解药：0 乘一百万还是 0。给自己留条缝：问「什么证据会让我改变想法？」答不上来就是先验已经钉死了。
→ 2.4 阴谋论者的贝叶斯
把反证解释掉
explaining away
症状：每条反驳都能想出说法，于是每次都觉得自己又「破解」了一层。
解药：能解释一切的理论什么也没预测。补丁要收费：它有没有带来新的可检验预测？
→ 2.4 阴谋论者的贝叶斯
「他们否认正说明是真的」
denial-as-evidence
症状：把对方的否认当成己方论点的证据。
解药：没做过的人也会否认。泛泛的否认似然比≈1，毫无信息量。
→ 2.4 阴谋论者的贝叶斯
只看眼前状态，不问来历
ignoring the generating process
症状：两个选项看上去对称，就当成等概率——不问它们各自是怎么变成现在这样的。
解药：概率不写在门上，写在门变成现在这样的历史里。问：这个筛选是按什么规则做的？
→ 3.1 蒙提霍尔问题
把自己放在中心
self-centred coincidence
症状：「怎么这么巧」——你算的是「发生在我身上」的概率，实际发生的是「发生在任何人身上」。
解药：先数机会数：一共有多少对、多少次、多少人？23 人有 253 对，不是 22 对。
→ 3.2 生日悖论
只看汇总数字
Simpson's paradox
症状：一个汇总比例显示出巨大差距，于是直接下结论。
解药：问：分组之后还成立吗？合并均值是按人数加权的，分布不均就能把结论翻过来。
→ 3.3 辛普森悖论
盲目「控制变量」
bad conditioning
症状：听说要控制混杂因素，于是见变量就分组。
解药：先问这个变量在因果链的哪一段：在原因之前（混杂）要控制，在原因之后（中介/对撞）控制反而制造假象。
→ 3.3 辛普森悖论
不问信息的来路
ignoring the information channel
症状：听到「已知 A」就直接算，不问「已知是怎么已知的」。
解药：同一句话，统计筛选出来的和随手报给你的，含义能差两个数量级。追问：这条信息是怎么到我手上的？
→ 3.4 两个孩子问题
赌徒谬误
gambler's fallacy
症状：连开 5 次红，觉得「该轮到黑了」。
解药：问一句「它凭什么记得？」——独立事件没有记忆，也没有补偿的义务。
→ 4.1 赌徒谬误与热手
连号一定有原因
streak overreading
症状：看到连中 5 球就断定「手感来了」，看到连亏 3 个月就断定「策略失效」。
解药：先问：纯随机的话这种连号多久出现一次？100 次抛掷里出现 7 连的概率过半。
→ 4.1 赌徒谬误与热手
「没发现效应」当「没有效应」
null result misread
症状：研究说没找到，就当作不存在。
解药：再问一句：尺子准吗？热手研究三十年的翻车，错的不是数据是估计量。
→ 4.1 赌徒谬误与热手
把回归均值当成疗效
regression to the mean
症状：「整治之后指标改善了」「骂完他就进步了」——挑的正是最差的那批。
解药：极端之后必然回落/回升。问：有没有同样极端、但没被干预的对照组？
→ 4.2 回归均值
把随机的扎堆当成信号
clustering illusion
症状：「这几例明显扎堆，肯定有原因」——心里的对照组是想象中的均匀分布。
解药：随机撒 537 点到 576 格，本来就有 227 格是空的、有格子挤 5 个。先算泊松基线再说。
→ 4.3 聚类错觉
先开枪再画靶
Texas sharpshooter
症状：发现异常之后才划定范围、提出假设，再用同一批数据证实它。
解药：提出假设的数据不能用来检验假设。事先划边界，用新数据验。
→ 4.3 聚类错觉
小分母的极端值
small-numbers volatility
症状：排行榜两端都是小单位，却被当成「最好」和「最差」的真实差异。
解药：分母小则波动大（约按 1/√n）。榜单两端同时看，方差就现形了。
→ 4.3 聚类错觉
幸存者偏差
survivorship bias
症状：「成功的人都早起」「这批老家具真结实」——你只看到了活下来的那些。
解药：问三句：什么样的样本会消失？消失机制和我的问题相关吗？我能找到失败样本吗？
→ 4.4 幸存者偏差
分子没有分母
numerator without denominator
症状：「我们孵化出 30 家独角兽」——听起来很厉害，可一共孵化了多少家？
解药：任何「成功案例数」都是分子。拿不到分母和筛选规则，分子不含任何信息。
→ 4.4 幸存者偏差
期望值为正就下重注
ignoring ruin
症状：「算过了，期望值是正的」——却没算下注比例会不会让你出局。
解药：期望值默认你能一直玩下去。破产删掉了这个前提。先问：这一注会不会让我出局？
→ 5.1 期望值 ≠ 好决策
只问方向不问仓位
position sizing blindness
症状：确认了「这事有利」就重仓压上，从不单独考虑该押多大。
解药：方向错了慢慢亏，规模错了迅速归零。先问：这占我总资源的百分之几？最坏会不会出局？
→ 5.2 凯利公式
用平均回报判断
mean vs median
症状：宣传里的「平均收益」很漂亮，可绝大多数人拿不到。
解药：问中位数是多少。两者差得越远，说明结果越依赖极少数幸运儿。
→ 5.2 凯利公式
拿正态分布量尾部
fat-tail blindness
症状：模型说「五个标准差、几千年一遇」，可它每隔几年就来一次。
解药：肥尾和正态在日常里无从分辨，差别全在尾巴。改问：如果它发生了，我还在不在？
→ 5.3 肥尾与黑天鹅
用历史数据估尾部风险
tail estimation from history
症状：十年数据里没出过事，于是认为不会出事。
解药：尾部的定义就是很少出现，你的样本里几乎必然缺它。而这个偏差只会让你低估，从不高估。
→ 5.3 肥尾与黑天鹅
拿集合平均当自己的账
non-ergodicity
症状：「这个机会期望收益为正」——可那是一千个人各做一次的平均，不是你重复做的结果。
解药：问：这个平均是谁的平均？如果我把它重复一百次，第一百次的我还在不在？
→ 5.4 最后一课
对不可逆的事算概率
irreversibility
症状：把「可能彻底完蛋」的选项和普通选项放在同一张期望值表里比较。
解药：不可逆 + 系统性 + 无法试错，三条都中就别算概率了，直接想办法把它变可逆。
